# Certificate model of CAPE (restricted lower bound) and its scope

This describes what `certificate: regime | all_regimes` reports (E0 and Eθ alike: Q1 changes no bound). Code:
`cpp/src/encoder.cpp` (`solve_regime`, regime loop), `cpp/src/dual_bound.cpp`, `cpp/src/byte_model.cpp`.

## 1. Byte model of the labels section (exact, upstream formula)
For widths `w = (w_L, w_I, w_G, w_N, w_D, w_C)`, `K_w` written labels, `G = Z` grids (slices), `P` pins and `Q` singleton
CC records:

  B_label = w_L + 8 + G·w_G + 1  +  K_w·(w_L + 2·w_N)  +  P·(w_I + w_D)  +  Q·w_C          (`predict_label_bytes`)

The first group is the fixed part `H(w)`; the second is the per-written-label overhead. The background label is not
written (`K_w = K − 1`). `w_N` and `w_D` are compacted after selection: the narrowest width that fits the written counts
and depths.

## 2. Per-regime set-cover model
- **Regime.** Fix a depth width `r = w_D ∈ {1, 2, 4, full}`; the longest pin is `h_r = min(Z, 2^{8r})`.
- **Candidates.** Inside one label `l`:
  - every candidate pin `j` (a depth-bounded complete window of a same-label column run) costs `c_r = w_I + r` and
    covers the CC set `C_j` of its chain;
  - every CC `u` can also be covered by a singleton record of cost `s = w_C`.
- **Decomposition.** The labels of a section are independent once the widths are fixed. Inside a label, CCs that share
  no candidate are independent components `k`, and `OPT_{r,l} = Σ_k OPT_{r,l,k}`.
- **Component problem** (all costs are integers):

  OPT_{r,l,k} = min { Σ_j c_r x_j + Σ_u s y_u :  Σ_{j ∋ u} x_j + y_u ≥ 1  ∀u ;  x, y ∈ {0,1} }

- **Safe reductions.** Singleton dominance, equal coverage (with M1a) and subset dominance remove only candidates that
  some optimal solution of the same model does not need. They preserve `OPT_{r,l,k}` (docs/mathematics.md;
  `tests/test_reductions_*`).

## 3. Integer dual bound (`dual_ascent`, `dual_feasible`)
- **Scaling.** `q = 2^20`, so `a_u = q·y_u`.
- **Ascent.** Visit CCs in ascending id and set `a_u = min(q·s, min_{j ∋ u} slack_j)`, where `slack_j` starts at
  `q·c_r`.
- **Feasibility check.** `a_u ≤ q·s` and `Σ_{u ∈ C_j} a_u ≤ q·c_r` for every remaining candidate `j`. This is checked
  independently by `dual_feasible`, in integer arithmetic only (no floats).
- **Weak duality.** For any feasible `a`, `Σ_u a_u / q ≤ OPT_LP ≤ OPT`. Because `OPT` is an integer,
  `L_{r,l,k} = ⌈Σ a_u / q⌉ ≤ OPT_{r,l,k}`.
- **Trivial components** (no candidate pin): `L = U = s·n`.

## 4. From component bounds to a section bound valid for every background and every count width
For regime r, with `L_l = Σ_k L_{r,l,k}`:

  LB_r = H(w with w_N = 1) + (K − 1)·(w_L + 2·1) + (Σ_l L_l − max_l L_l)

- **`w_N = 1`.** The written `w_N ≥ 1`, and the bound uses the smallest value.
- **Background.** It removes one label's records. The best case removes the label with the largest bound, hence
  `− max_l L_l`.
- **Total.** The reported total LB adds the non-label part of the stream, which is identical for every label encoding
  (header, crack codes, crcs).

## 5. Over regimes, and the w_D compaction fix (found in v3)
- **Global restricted bound.** `LB = min_r LB_r` is a lower bound over the whole restricted family only if every
  regime is bounded.
  - `all_regimes` adds dual-only bounds for the regimes the FAST stream search skipped.
  - `regime` reports the evaluated regimes, plus the fix below.
- **The fix.**
  - A fixed-depth (FAST) stream may compact `w_D` below the regime width when no chosen pin is that deep. Such a stream
    is a cover from full-width runs of length `≤ h_w`, priced at `c_w = w_I + w`.
  - The full-width bound does not cover that family. v2.1 therefore reported `lb > ub` on 12 rows of the
    `cape_fixed_depth_width` ablation (v1/v2 width runs, Z = 512).
  - v3 adds the full-width dual scaled by `c_w / c_full`. Every full-width candidate's dual sum is `≤ q·c_full`, so
    scaling gives `≤ q·c_w`; the scaled dual is feasible for that family. Its bound is included for every narrower `w`.
  - Stream bytes are unchanged; only the reported LB changes.
  - Audit table: `audit/certificate_propagation.csv` (Q1), generated by `tools/q1_audit.py`.

## 6. Gap and status
- **Gap** = `(UB − LB)/UB`, where UB is the size of the written stream (a real, decoded, feasible encoding).
- **Status.** A component is "LbTight" when `U = L` (optimal within the model) and "ExactDp" when the bitmask DP proves
  the optimum; otherwise "Heuristic".
- **Oracle.**
  - CP-SAT checks exported components (`cape/oracle.py`) and records the solver version, status, time, incumbent and
    best bound.
  - Only `OPTIMAL` counts as proven. `FEASIBLE` or a timeout is reported as such, never as optimal.

## 7. Scope (what the certificate does NOT say)
- It bounds the **restricted** model only: the depth-bounded complete-window candidate family, the safe reductions,
  pins format, all depth regimes (when all are evaluated), all backgrounds, `w_N ≥ 1`.
- It is not a bound over all conceivable pin sets, over the FLAT format choice, or over upstream Crackle's own
  encoder space.
- It says nothing about sizes after zstd: zstd is not additive over records, so no archive bound is claimed.
- The certificate does not prune FAST: the regime gate (M3a) is QUALITY-only, and FAST does not use the bound in
  decisions.
  - The audit checks that the v2.1 invalid bound did not influence any selection: the v2.1 and v3 stream bytes are
    equal on those rows.
